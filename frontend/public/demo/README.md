# Demo assets

These fictional images were generated for LotTrace, not captured from live cameras.

- `dealership.png`: a four-image sheet showing KJ72 XLM arriving, leaving at dusk, and two bumper inspections (unmarked / possible scrape).
- `fleet.png`: a four-image sheet of a white BMW, black Volkswagen, silver Toyota at dusk, and red Mazda.

The UI displays source regions through SVG viewports; bounding boxes and OCR readings are illustrative. Demo dates, cameras, confidence values and records are fictional. Repeated frames are intentionally reused in the demonstration timeline. This is not an evidence archive.
